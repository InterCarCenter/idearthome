# IdeartHome | Sitio web

Sitio estático para **IdeArtHome**: muebles y decoración en Bogotá (catálogo, contacto y reseñas).

## Requisitos

- Node.js 18 o superior

## Instalación y desarrollo

```bash
npm install
npm run dev
```

Build de producción:

```bash
npm run build
npm run preview
```
